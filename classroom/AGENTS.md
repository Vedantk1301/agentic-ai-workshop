# Beginner classroom examples

Teach one small canteen agent from a new file. Keep ordinary tools readable and reuse them unchanged through the local MCP server. Completed files are checkpoints; the new-file lesson is README.md.

- Explain the intended behavior before editing.
- Keep the fictional menu records and labelled mock clock consistent.
- Scripted models are rehearsal support, not real AI.
- Keep MCP stdout reserved for protocol messages.
- Never open, print or commit private .env files or keys.
- Run classroom tests and relevant commands. Distinguish offline integration checks from real Gemini calls.
